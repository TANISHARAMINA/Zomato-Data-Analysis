Zomato Restaurants Data Analysis

Project Definition:
This project analyzes the Zomato Restaurants dataset to understand ratings, cuisines, cities, and customer preferences.

 Dataset Usecase:
- Source: Kaggle Zomato Restaurants dataset
- Cleaned by removing duplicates and missing values
- Columns used: Aggregate rating, Cuisines, City, Price range, Votes, Online delivery

Visualizations:
- Rating Distribution (Histogram)
- Top 10 Cuisines (Bar chart)
- Top 10 Cities (Bar chart)
- Price Range vs Rating (Boxplot)
- Online Delivery vs Rating (Boxplot)
- Votes vs Rating (Scatter + Regression)

Tools & Libraries:
- Python
- Pandas
- Matplotlib

Outcomes:
- Most restaurants have ratings between 3–4
- Certain cuisines and cities dominate the dataset
- Votes positively correlate with ratings
